## Risiko terbesar

1. **Lockout akun lama** jika kewajiban lokasi langsung dipaksakan. Mitigasi: `GRACE` 30 hari + banner + backfill demo.
2. **Inkonsistensi angka** antara Dashboard, peta, Kinerja, CSV, print, PDF. Mitigasi: satu fungsi agregasi berbasis `approved_at` + tes rekonsiliasi.
3. **Klaim kapasitas 100k tanpa bukti**. Mitigasi: dataset sintetis + load test staging; produksi tetap `NOT VERIFIED`.
4. **Migrasi produksi**. Mitigasi: migrasi aditif, backup wajib, rehearsal staging, rollback aplikasi kompatibel.
